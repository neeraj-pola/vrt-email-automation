# Frontend

React + TypeScript + Vite dashboard for VRT Email Automation. Setup, settings, running and deployment
are in the [repository README](../README.md).

```
npm install
cp .env.example .env.local     # fill in VITE_API_URL and the VITE_FIREBASE_* values
npm run dev                    # http://localhost:5173
npm test                       # logic tests for the Modify draft page
npm run build                  # type-check and production build
```
